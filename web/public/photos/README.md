# Press photos

Drop real photos into `static/photos/<category>/` (jpg, png, webp, avif or svg).
Categories: exam, deadline, event, academics, sports, general.
`default.svg` is used when a category folder is empty.

Optional `credits.json` in a category folder maps filename to credit line:
`{"lab-bench.jpg": "Photo: A. Student"}`.

The placeholder SVGs here are stand-ins; replace or add to them freely.
